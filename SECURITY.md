# Security policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities, exposed credentials, private data or security-sensitive operational details in public issues or pull requests.

Send a concise report to **ssswetindustries@gmail.com**. Include the affected public component, the potential impact and enough information to reproduce the issue safely. Do not include real personal data or active credentials.

Please allow the project maintainers reasonable time to review a report before making technical details public. A response time or coordinated-disclosure deadline is not guaranteed.

## Credentials and private data

Never commit API keys, access tokens, passwords, private keys, database files, personal information or unpublished research material. If a credential is exposed, revoke or rotate it immediately; deleting the visible file is not sufficient because repository history, forks and caches may retain copies.

## Scope

This policy covers the public SSSWET repository and its published website. It does not grant authorization to access systems, accounts, data or services without permission.
