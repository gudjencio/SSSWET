# Contributions

The official SSSWET repository is maintained by its project owner, Gudjencio MARTIN.

At this time, external code contributions and pull requests are not accepted. The project owner controls changes to the official source tree. Public issues may be used for concise bug reports or general feedback; do not include confidential concepts, unpublished inventions, credentials or personal data.

Submitting an issue does not grant permission to modify the official repository, use the SSSWET name or represent an independent project as official.

The public website and repository are available for reading. A user may create an independent copy where the applicable license permits it, but an independent copy must not use the SSSWET name, logo or branding to imply that it is the official project. See [NOTICE.md](NOTICE.md).
