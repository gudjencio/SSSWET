RESEARCH INTERFACE

SSSWET

Research ideas. Test them. Verify them. Never confuse a hypothesis with reality.

Local research engine not connected

The public interface is available in fallback mode. Live local research data will appear automatically when the engine is running.

To enable live data, run cd SSSWET/core, python -m pip install -e ., then ssswet-local on the computer hosting the engine. Allow local-network access if your browser requests it.

If your browser blocks access from this hosted page, open the local interface directly after starting the engine: http://127.0.0.1:8765/. This same-origin route avoids cross-origin local-network restrictions.

On Windows, the repository also includes a local engine launcher for the initial setup and startup.

While offline, explore the Research documentation, Research integrity framework and Technology contribution policy.
